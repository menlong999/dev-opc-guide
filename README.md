# 大龄程序员失业后 OPC（一人公司）指南

**从想清楚做什么，到公司、备案、收款、上架，再到把生意持续做下去。持续更新。**

失业以后，想试试自己做点事，第一步该做什么？

产品有人需要，代码也写出来了，为什么还是没法下载、没法收钱、过不了审核？

这份指南从我的实际经历出发：注册公司、对公开户、网站和 App 备案、微信支付、Apple 上架，以及 WorkBuddy 的连接器、专家和 Buddy App。把来回折腾的过程写下来，让后来的人少从头猜一遍。

面向大龄程序员、失业后考虑转向独立开发的人，以及准备经营一人公司的开发者。这里的 OPC 指一个人经营公司的方式，具体工商主体另看注册章节。

## 这份指南怎么读

先选自己的产品形态、所在地区、主体和目标平台，再看相近经历。公司设立、网站备案、App 备案、经营许可、平台审核是不同事项，一个通过不会自动替你完成其他申请。

主体办理和产品上线部分有我的实际经历；方向、获客和经营部分提供准备问题与做法建议，后续继续补充具体实践。

首版整理：2026-10-31。办理入口和平台要求可能变化，涉及下一步操作的条件写在对应问题里。
