## App 收会员费，就一定要办 ICP 许可证吗？

不能只凭“收费”两个字决定。先写清楚实际业务：卖什么、谁提供服务、有没有其他主体入驻销售、是否为其他用户提供信息发布平台，再核对适用的业务分类。

广东管局的公告列出了自营销售、自行发布信息等附带具体条件的无需许可情形。我当时也是靠评论提示，才找到主管部门原文。[查看公告](https://gdca.miit.gov.cn/bsfw/bszn/jyxk/tzgg/art/2022/art_da255ff756604fd5afe158c2fa96a17f.html)。

<a id="q029"></a>

## 自营软件、内容订阅和第三方入驻，应该怎么描述自己的业务？

按真实流程描述：用户向谁购买、款项由谁收、服务由谁提供、第三方能否以自己名义售卖、用户能否面向其他用户发布信息。不要只写“互联网服务”或“AI 平台”。

把这份业务说明拿给主管部门或平台核对，比在“经营性”“会员”几个词之间反复猜测更有用。业务变更后也要重新看。

<a id="q030"></a>

## 中介建议办 ICP 或 EDI，怎么判断自己是否真的需要？

先问清建议对应哪一项真实业务、依据哪条要求、由哪个机关受理，再查主管部门说明。我当时也被建议办 EDI，后来才继续核对业务条件。

广东管局明确说明未指定申请中介、不向申请人收取相关申请费用。代办服务费和政府申请收费要分开看。[查看官方说明](https://gdca.miit.gov.cn/bsfw/bszn/jyxk/tzgg/art/2022/art_da255ff756604fd5afe158c2fa96a17f.html)。

<a id="q031"></a>

## 看到了无需许可的公告，平台还是要证件，怎么办？

先请平台说明具体缺什么、对应哪个服务类目、能否按实际业务补说明或复核，再向主管部门咨询业务分类，保留书面答复。

评论里有另一位开发者自述，在公安备案、应用市场和广告认证中仍被要求提供许可证。我自己的反应是：实际办理与对公告的理解还要继续核对。这是他人的个案，不能据此预判所有平台。

<a id="q032"></a>

## 软著申请要准备什么，AI 写过的代码还能不能申请？

我已经整理过一套软件操作手册、代码清单、界面截图、版本说明和导出样例。这能说明材料准备的工作量，但材料包本身不是获证结果。

关于 AI 代码，评论里有互相矛盾的经验。申请时应如实说明权利和开发情况，核对中国版权保护中心当前要求；被退回就按具体原因修改，不按网友一句话判断必过或必不过。

<a id="q033"></a>

## 电子版权能代替软著上架 Android 吗，值得先花钱吗？

在我当时的讨论里，约 600 元电子版权只是候选方案，没有形成“付费购买后获证并成功上架”的结果。不能写成每个商店都接受。

花钱前先向目标商店确认具体证书类型、出具机构、产品和版本要求，以及是否接受替代材料。官网直接发 APK 也要考虑手机安装提示和用户信任，不能只比较上传文件的难易。
