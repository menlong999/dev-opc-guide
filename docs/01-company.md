# 公司注册、对公开户与日常成本

[返回首页](../README.md) · [全部问题](README.md) · [踩坑索引](../cases/README.md)

## 我当时的办理顺序

先到行政服务中心咨询，确认可以自己线上办；再准备备选名称、企业类型、主营范围和地址信息；按系统完成申请，选择刻章与领证方式。执照审批通过后，继续安排对公开户与经营核验。

开户之外，再安排财税、发票和日常资料管理。下面按每一步遇到的问题展开。

<a id="q009"></a>

## OPC 是一种单独的工商企业类型吗？

我这里说的 OPC，是一个人经营公司的工作方式。我实际注册时选择的是“有限责任公司（自然人独资）”。不要直接拿 OPC 这个称呼去对应工商表单，也不要和“个人独资企业”混选。

先确定要申请的平台接受什么主体，再在登记系统确认对应企业类型。

<a id="q010"></a>

## 公司名字怎么准备，才能少在核名上来回折腾？

我最初尝试两字名字，连自己的名字也试过，都遇到重名，最后用了四字名字。可以提前准备多组不同字号，边核名边调整。

这是我在深圳宝安办理时的经历，不能据此断言两字名称一定不能注册。

<a id="q011"></a>

## 注册资本怎么定，认缴意味着可以完全不管吗？

不要为了显得有实力随手填大数字。先确认认缴金额、出资安排和实际承担能力，再通过登记机关的现行说明确认期限与责任；合同或平台申请另有资本要求时，也要拆开判断。

这里不提供一套适用于所有设立日期和主体类型的金额、期限答案。开始填表前，先把这笔真实义务弄清楚。

<a id="q012"></a>

## 经营范围越多越好吗，行业分类报错怎么处理？

我当时勾了很多经营范围，系统一直提示行业分类不对。后来先调整主营项目和行业分类，再逐项增加所需范围，才继续办下去。

遇到这类错误，先核对主营与分类的匹配关系，保留报错文字，再找窗口确认。不要把问题一概归因于勾选数量。

<a id="q013"></a>

## 注册地址一定要租办公室或付挂靠费吗？

我这次直接用了自家住宅地址和房屋编码，没有为注册地址另租工位。能不能照办，要看具体城市、房屋用途及申请条件。

付地址费用前，先向当地登记窗口确认自己的地址能不能用、需要哪些证明，以及银行和后续平台是否有额外要求。

<a id="q014"></a>

## 营业执照、印章和领证方式，哪些会影响实际耗时？

我的记录是周一填材料、周三上午审批通过，申请时勾选免费刻章。审批快，但选择邮寄又多等了几天。

分别看填表、审批、制证和到手时间。赶后续开户或申请时，提前问清自取与邮寄安排；不要把我这次耗时当作办理时限承诺。

<a id="q015"></a>

## 老银行客户办对公账户，也可能要反复预约吗？

我原本是招行个人客户，在客户端预约对公开户，等了一天，又打了四次电话才联系上经理，随后被告知客户端预约不算。

换微众后，线上填资料约五分钟，约二十分钟后顺丰上门核验，拍照约两分钟。这是两次具体体验；选银行还要核对功能、限额、费用和业务适用性。

<a id="q016"></a>

## 上门核验需要准备什么，一个人在家办公能不能办？

我当时不需要公司招牌，但需要能体现电脑办公的实际场景。自己的地址能否用于该账户、资料是否完整，应直接向开户银行确认。

预约前准备营业执照、身份及经营场所材料清单，并核实核验人员身份和办理渠道。不要按网上截图猜银行当前要求。

<a id="q017"></a>

## 零元办照之后，记账、报税、社保和发票怎么安排？

我的“零元”指自己办理营业执照、没付地址租赁费，以及当时的免费刻章。后来的税务、社保和发票，我找了代办。

没有收入也应先问清申报义务和时间。向财税服务方问清服务范围、包含项目、额外收费、资料交接和退出方式，拿到清单再比较。

<a id="q018"></a>

## 执照还没收到就有人打代办电话，怎么分辨和处理？

我确实在执照到手前收到过税务代办电话，但没查清信息究竟从哪个环节流出。

接到电话先核对机构和服务内容；涉及办理要求时，通过登记、税务等官方渠道确认。不要因为对方说得出公司名称，就直接付款或交出证件。
